# ملفاتي — مستعرض ملفات شخصي لأندرويد

تطبيق Kotlin + Jetpack Compose للاستخدام الشخصي (غير منشور على المتجر).

## التثبيت
افتح تبويب **Releases** في هذا المستودع، ونزّل أحدث ملف `MyFiles-v*.apk` وثبّته.
كل تعديل يُرفع على الفرع `main` يبني نسخة جديدة تلقائيًا، وكلها موقّعة بنفس المفتاح فتُحدَّث فوق القديمة.

## المزايا
- تصفّح، نسخ، نقل، حذف، إعادة تسمية، بحث، ترتيب وفلترة، عرض قائمة أو شبكة
- واجهة عربية من اليمين لليسار، وضع فاتح وداكن وأسود حقيقي، 4 ألوان تمييز أو ألوان النظام
- لوحتان جنبًا إلى جنب وشريط مواقع جانبي ولوحة تفاصيل على التابلت
- المهملات مع الاستعادة والحذف التلقائي بعد مدة تختارها
- ضغط وفك ضغط ZIP
- عارض مدمج للصور (تكبير وتنقل)، والفيديو والصوت، والنصوص (مع تعديل)، وPDF
- محلل المساحة: التوزيع حسب النوع، أكبر الملفات، الملفات المكررة
- الشبكة: SMB وFTP وSFTP مع النسخ من وإلى الخادم

## ملاحظات
- يحتاج إذن «الوصول إلى كل الملفات».
- مفتاح التوقيع موجود في `keystore/` لأن المستودع خاص والاستخدام شخصي.
- كلمات مرور الاتصالات تُحفظ داخل مساحة التطبيق الخاصة على الجهاز.
- الخط: Readex Pro برخصة SIL OFL.
